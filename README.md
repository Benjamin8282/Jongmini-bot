# 🐣 종미니 (Jongmini Bot)

## 🚀 프로젝트 개요

**종미니 봇**은 네오플의 던전앤파이터(DNF) 오픈 API를 활용하여 DNF 캐릭터의 게임 내 활동(타임라인)을 실시간으로 모니터링하고, 특정 아이템 획득 시 디스코드 채널에 자동 알림을 전송하는 지능형 디스코드 봇입니다. 단순한 알림을 넘어, 모험단(계정) 및 캐릭터별 아이템 획득 통계를 일간, 주간, 월간, 시즌별로 집계하여 사용자에게 심층적인 데이터를 제공합니다.

이 프로젝트는 Python의 비동기 프로그래밍 역량과 Discord 봇 개발 경험을 심화하고, 안정적인 서비스 운영을 위한 CI/CD 파이프라인 구축 능력을 보여주기 위해 개발되었습니다.

## ✨ 주요 기능 및 특징

*   **실시간 득템 알림**:
    *   등록된 캐릭터의 타임라인을 주기적으로 조회하여 장착 가능 레벨 115 이상의 아이템 획득 이벤트를 감지합니다.
    *   감지된 득템 정보는 설정된 디스코드 채널에 즉시 축하 메시지와 함께 전송됩니다.
    *   다중 캐릭터 관리 및 중복 득템 알림 방지 로직이 적용되어 정확하고 효율적인 알림을 제공합니다.
*   **다양한 통계 및 랭킹**:
    *   **일간/주간/월간/시즌별 아이템 획득량 집계**: 모험단별 아이템 획득량을 자동으로 집계하고 순위를 매겨 보여줍니다.
    *   **캐릭터별 주간 집계**: 특정 캐릭터의 주간 아이템 획득 현황을 상세히 분석합니다.
    *   **정확한 순위 처리**: 동점자 처리 로직을 개선하여 공정한 랭킹을 제공합니다.
    *   **기간 분할 처리**: 장기간의 데이터를 효율적으로 집계하기 위해 최대 90일 단위로 기간을 분할하여 API 호출 부하를 관리합니다.
*   **직관적인 슬래시 커맨드**:
    *   `/hello`: 봇의 활성화 상태를 확인합니다.
    *   `/등록 <서버> <캐릭터명>`: 모니터링할 캐릭터를 등록하고 타임라인 감시를 시작합니다.
    *   `/출력`: 득템 알림 및 통계 메시지를 받을 디스코드 채널을 설정합니다.
    *   `/오늘현황`, `/주간현황`, `/월간현황`, `/시즌현황`: 각 기간별 모험단 아이템 획득 현황 및 순위를 조회합니다.
    *   `/주간캐릭터현황`: 특정 캐릭터의 주간 득템 현황을 조회합니다.
*   **자동화된 작업 스케줄링**:
    *   `APScheduler`를 활용하여 일간, 주간, 월간 집계 작업을 정해진 시간에 자동으로 실행합니다.
    *   봇 부팅 시 미실행된 집계 작업을 감지하여 즉시 실행함으로써 데이터 누락을 방지합니다.

## 🛠 기술 스택 및 아키텍처

이 프로젝트는 Python의 강력한 비동기 기능을 적극 활용하여 효율적이고 확장 가능한 아키텍처를 구축했습니다.

*   **언어**: Python 3.11+
*   **디스코드 봇 프레임워크**: `discord.py` 2.x
    *   최신 슬래시 커맨드(Slash Commands)를 지원하여 사용자 친화적인 인터페이스를 제공합니다.
*   **비동기 HTTP 클라이언트**: `aiohttp`
    *   네오플 DNF 오픈 API와의 비동기 통신을 담당하여 API 호출 지연이 봇의 전체 성능에 영향을 미치지 않도록 합니다.
*   **비동기 프로그래밍**: `asyncio`
    *   주기적인 타임라인 감시, API 호출, 데이터 처리 등 모든 핵심 로직을 비동기적으로 처리하여 높은 동시성과 응답성을 보장합니다.
*   **비동기 SQLite 데이터베이스**: `aiosqlite`
    *   캐릭터 등록 정보, 출력 채널 설정, 아이템 캐시, 마지막 집계 시간 등 봇의 영속적인 데이터를 비동기적으로 관리합니다.
    *   가볍고 빠르며, 별도의 데이터베이스 서버 구축 없이 파일 기반으로 운영되어 배포 및 관리가 용이합니다.
*   **작업 스케줄러**: `apscheduler`
    *   정기적인 데이터 집계(일간, 주간, 월간) 및 알림 작업을 안정적으로 스케줄링하고 실행합니다.
*   **환경 변수 관리**: `python-dotenv`
    *   API 키, 디스코드 토큰 등 민감한 정보를 `.env` 파일에서 안전하게 관리하여 코드와 분리합니다.
*   **로깅**: `logging` 모듈
    *   `core/logger.py`를 통해 체계적인 로깅 시스템을 구축하여 봇의 운영 상태, 오류, 주요 이벤트 등을 기록하고 모니터링합니다.

## 🚀 배포 및 운영 자동화

이 프로젝트는 안정적인 서비스 운영과 효율적인 배포를 위해 Docker와 GitHub Actions를 활용한 CI/CD 파이프라인을 구축했습니다.

*   **Docker 기반 컨테이너화**:
    *   `Dockerfile`을 통해 봇 애플리케이션을 컨테이너 이미지로 패키징하여 환경 독립적인 배포를 가능하게 합니다.
    *   도커 볼륨을 활용하여 `data/characters.db` 및 `logs/` 디렉토리의 데이터를 영속적으로 관리, 컨테이너 재생성 시에도 데이터 손실 없이 무중단 업데이트를 지원합니다.
*   **GitHub Actions를 통한 CI/CD**:
    *   `.github/workflows/docker-publish.yml` 워크플로우를 통해 소스 코드 변경(push) 시 자동으로 Docker 이미지를 빌드하고 Docker Hub에 푸시합니다.
*   **Portainer API를 활용한 자동 재배포**:
    *   Portainer API를 호출하여 Docker Hub에 새로운 이미지가 푸시되면, 운영 중인 컨테이너가 최신 이미지를 자동으로 `Repull`하고 재시작되도록 자동화했습니다. 이를 통해 수동 개입 없이 최신 버전의 봇을 항상 운영할 수 있습니다.
